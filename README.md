# THE PUSTAK REPOSITORY

## Library Management System

THE PUSTAK REPOSITORY is a Library Management System developed using Java, Spring Boot, MySQL, HTML, CSS and JavaScript.

The project is designed to manage library users and books through a simple web-based platform.

## Current Modules

### 1. User Management
- Add new users
- View users
- Update user details
- Manage user information
- Connected with MySQL database

### 2. Book Management
- Add new books
- View books
- Update book details
- Delete books
- Search and filter books
- Track total and available copies
- Connected with MySQL database

## Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- REST API
- Maven
